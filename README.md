# 🤖 Spirit AI – Smart LINE Bot System

Spirit AI คือระบบ LINE Bot สำหรับบริหารจัดการงานในกลุ่ม  
รองรับการแจ้งเตือนอัตโนมัติ, รายงานสถิติ, บันทึกข้อมูล และระบบทะเบียนสมาชิก

ออกแบบมาเพื่อใช้ในองค์กร / คริสตจักร / ทีมงาน ที่ต้องการระบบจัดการภายในแบบอัตโนมัติ

---

## 🚀 ความสามารถของระบบ

### 📊 1. ระบบรายงานจังหวัด
- แจ้งเตือนส่งสถิติทุก 08:00
- วันอาทิตย์ / จันทร์ / อังคาร / ศุกร์
- รองรับ 6 จังหวัด
- อัปเดตสถานะเมื่อส่งแล้ว
- ไม่แจ้งซ้ำจังหวัดที่ส่งแล้ว

---

### 📈 2. ระบบสถิติหาดใหญ่
- แจ้งเตือนทุกวันอาทิตย์ 13:00
- กรอกตัวเลขได้หลายแบบ:
  ```
  pro=20
  stb=10
  pro=20 stb=10
  ```
- สรุปผลแบบ realtime

---

### 🔔 3. ระบบแจ้งเตือนล่วงหน้า (Reminder System)

#### บันทึกแจ้งเตือน
```
แจ้งเตือน วาเลนไทน์ 14/2/2026
```

#### คุณสมบัติ
- รัน ID อัตโนมัติแบบไม่ชนกัน
- บันทึกชื่อผู้บันทึก
- แยกตาม groupId

#### แจ้งเตือนอัตโนมัติ
⏰ ทุกวัน 07:00

- 🔔 แจ้งล่วงหน้า 3 วัน
- 📌 แจ้งวันจริง
- รวมหลายรายการเป็นข้อความเดียว
- ใส่ ID ในข้อความ
- กันยิงซ้ำ 2 ครั้ง

#### ลบแจ้งเตือน
```
ลบ 3
```

---

### 📝 4. ระบบบันทึกถาวร
```
บันทึกลา สมาย 12/03/2026
```
- เก็บข้อมูลแบบถาวร
- เรียกดูย้อนหลังได้

---

### 📘 5. ระบบรายงานการรับใช้
```
รายงานการรับใช้ วันนี้ไปดูแลคน
```
- บันทึกตามสัปดาห์
- สรุปผลประจำสัปดาห์

---

### 👤 6. ระบบทะเบียนสมาชิก
```
ลงทะเบียน สมาย 19/10/1993 เบอร์โทร...
```

ค้นหาได้:
```
ขอข้อมูลทะเบียนเดือน10
```

## ⚙ ระบบ Scheduler

ระบบทำงานอัตโนมัติด้วย node-cron

| เวลา | ระบบ |
|------|------|
| 07:00 ทุกวัน | Reminder ล่วงหน้า 3 วัน + วันจริง |
| 08:00 | รายงานจังหวัด |
| 09:00 | แจ้งเตือนวันอาทิตย์ |
| 11:30 | เพลงตอบสนอง |
| 12:00 | โปรแกรมวันอาทิตย์ / ซ้อม |
| 13:00 | สถิติหาดใหญ่ |
| 15:00 | แจ้งเตือนวันเสาร์ |

Timezone: Asia/Bangkok

## 🛡 ความปลอดภัยของระบบ

- แยกข้อมูลตาม groupId
- ใช้ Firestore Transaction กัน ID ชน
- มี flag ป้องกันยิงแจ้งเตือนซ้ำ
- ครอบ try/catch ทุก module
- Production ready บน Render
