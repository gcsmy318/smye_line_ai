# 🤖 Spirit AI - LINE Bot System

ระบบ LINE Bot สำหรับจัดการงานภายในกลุ่ม เช่น
- แจ้งเตือนส่งสถิติ
- บันทึกข้อมูลถาวร
- ระบบทะเบียนสมาชิก
- รายงานการรับใช้
- ระบบแจ้งเตือนล่วงหน้า
- ระบบสถิติหาดใหญ่

พร้อม Admin Panel สำหรับดูแลข้อมูลกลุ่ม

---

# 🚀 ความสามารถของระบบ

## ✅ 1. ระบบรายงานจังหวัด (เซ็ต1)
- แจ้งเตือน อา จ อ ศ เวลา 08:00
- จังหวัด: สงขลา สตูล ปัตตานี ยะลา นราธิวาส พัทลุง
- ผู้ใช้พิมพ์:  
  `สงขลา ส่งสถิติแล้ว`

---

## ✅ 2. ระบบสถิติหาดใหญ่ (เซ็ต2)
- แจ้งเตือนทุกวันอาทิตย์ 13:00
- ผู้ใช้พิมพ์:  
  `pro=20`  
  `pro=20 stb=10`

---

## ✅ 3. ระบบแจ้งเตือนล่วงหน้า (เซ็ต3)
- เตือนก่อนงาน 3 วัน เวลา 08:00
- พิมพ์:  
  `แจ้งเตือน ค่าย 1/3/2569`

---

## ✅ 4. ระบบบันทึกถาวร (เซ็ต4)
- บันทึกลา / บันทึกข้อมูลสำคัญ
- พิมพ์:  
  `บันทึกลา สมาย 12/03/2026`

---

## ✅ 5. ระบบรายงานการรับใช้ (เซ็ต5)
- บันทึกสิ่งที่ทำรายสัปดาห์
- พิมพ์:  
  `รายงานการรับใช้ วันนี้ไปดูแลคน`

---

## ✅ 6. ระบบทะเบียนสมาชิก (เซ็ต6)
- บันทึกวันเกิด + เบอร์โทร
- พิมพ์:  
  `ลงทะเบียน สมาย 19/10/1993 เบอร์โทร...`

---

## ✅ 7. ดูสถานะระบบ (เซ็ต7)
- ตรวจสอบว่ากลุ่มเปิดระบบอะไรอยู่

---
